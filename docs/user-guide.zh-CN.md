# Cymple Streamer 使用指南

适用版本：**0.16.6** · 更新日期：**2026 年 10 月 22 日**

## 1. 安装与首次连接

### 1.1 准备条件

| 项目 | 需要准备什么 |
| --- | --- |
| 电脑 | Windows 10 / 11；能运行目标游戏、并支持所选视频格式的显卡 |
| PC VR 游戏 | Steam、SteamVR，以及准备游玩的游戏 |
| Android 头显 | 与本项目 APK 兼容的 VR 头显，例如具备相应支持的 Quest、PICO 设备 |
| Steam Frame | 使用专用安装器，按[下一节](#steam-frame)操作 |
| 无线网络 | 电脑与头显在同一局域网；建议电脑通过网线连接路由器，头显使用 5 GHz 或受支持的 6 GHz Wi-Fi |
| USB 连接 | 支持数据传输的线缆，并按对应头显的步骤授权 |

不同型号的刷新率、分辨率、视频格式、透视和追踪功能可能不同。先连接头显，再根据软件显示的支持情况选择设置；灰色或标注「不支持」的项目不可作为当前设备的可用功能。

### 1.2 安装 Windows 电脑端

1. 从[下载页](https://github.com/Dominocs/Cymple_Streamer_Download/releases/tag/latest)获取 `Cymple_Streamer_Setup_v版本号.exe`。
2. 结束当前串流并关闭 SteamVR，运行安装器，按提示完成安装。出现 Windows 权限提示时允许安装。
3. 首次安装虚拟音频设备后，如果安装器要求重启 Windows，先完成重启。
4. 打开 Cymple Streamer。需要玩 PC VR 游戏时，确保 Steam 与 SteamVR 已安装完成。
5. 如果 Windows 询问网络访问权限，允许应用在你用于串流的网络上通信。

### 1.3 安装 Android 头显端

1. 下载配套的 `cymple_streamer_android_v版本号.APK`。
2. 按头显厂商提供的方法启用开发者功能，并使用支持该设备的 APK 安装工具安装文件。
3. 在头显应用列表中找到 Cymple Streamer；通过开发者方式安装的应用可能位于「未知来源」一类的列表中。
4. 打开应用。使用麦克风、眼动、面部或身体追踪时，按需授予对应权限。

电脑端和头显端优先使用同一发行版提供的配套文件。不要将 Steam Frame 当作 Android 头显安装 APK。

### 1.4 完成第一次串流

1. 打开电脑端和头显端。
2. 完成 [Wi-Fi 或 USB 连接](#connection)。
3. 在头显「电脑」页，指向目标电脑并按扳机选择。
4. 确认能看到桌面、移动指针并点击窗口，再检查电脑声音。
5. 需要玩游戏时，从头显菜单选择「启动 STEAMVR」。

初次使用先保留默认设置。遇到卡顿时降低画面分辨率或码率；连接稳定后再逐项调整画质、注视点串流和帧生成。

## 2. Steam Frame 安装与启动

Steam Frame 使用专用安装器 `CympleStreamerSteamFrameSetup.exe`，需要在 Windows 电脑上运行。**截至本指南更新日，[公开下载页](https://github.com/Dominocs/Cymple_Streamer_Download/releases/tag/latest)列出的应用安装包为 Windows 电脑端和 Android APK，尚未列出 Steam Frame 专用安装器。**使用本节前，请先向发布者取得配套版本的专用安装器；后续提供下载时以发布页为准。

### 2.1 安装

1. 在 Steam Frame 中打开「Steam 设置 → 系统」，启用开发者模式；也可查看安装器中的「开发者模式说明」。
2. 用 USB 数据线连接头显与电脑，保持头显唤醒、Steam 运行；出现 USB 调试授权时确认允许。
3. 在 Windows 上打开专用安装器，点击「刷新设备」。
4. 确认检测到 Steam Frame，填写「Devkit Game 名称」。首次使用可保留 `Cymple_Streamer`。
5. 点击「安装」，等待安装器显示完成。
6. 在头显中进入「库 → 非 Steam」，打开 `Devkit Game: Cymple_Streamer`；如果改过名称，打开对应名称的条目。
7. 打开 Windows 电脑端，在头显「电脑」页手动选择要连接的电脑。

安装完成后需要自己从头显游戏库打开应用。USB 安装成功只表示程序已装好；实际串流仍需在「电脑」页选择可用连接。

### 2.2 更新与卸载

用同样的方法连接设备，在安装器中选择「更新」或「卸载」。已有程序使用「更新」，尚未安装时使用「安装」。操作完成前保持头显唤醒、线缆连接和 Steam 运行。

遇到检测或安装失败，先查看安装器的「操作记录」或点击「打开记录」。没有看到设备时，检查数据线、开发者模式和头显中的授权提示。

### 2.3 使用注意

- Steam Frame 启动后需要手动选择电脑。
- 当前视频格式使用 H.264 或 HEVC；不要按 Android 设备的说明启用 AV1、HEVC-10Bit 或 HDR。
- 头显自身的每应用画质和刷新率设置也会影响体验。画面或刷新率不符合预期时，同时检查这些设置。
- 桌面和游戏的切换、键盘快捷键见[桌面操作](#desktop)。未提供或不可选的功能以当前界面提示为准。

## 3. 连接方式

### 3.1 Wi-Fi 无线连接

1. 将电脑和头显连接到同一局域网。
2. 打开两端程序，等待头显「电脑」页出现电脑名称。
3. 选择带 `WIFI` 标记的条目。

建议电脑接网线，头显靠近路由器。访客 Wi-Fi、设备隔离或某些 VPN 设置可能让两端无法互相发现；找不到电脑时，先检查这些项目。

### 3.2 Quest USB 有线连接

1. 使用支持数据传输的 USB 线连接电脑与头显。
2. 打开两端程序，按头显提示允许 USB 网络连接。
3. 在「电脑」页等待带 `USB` 标记的电脑出现，然后选择该条目。

此方式需要头显系统支持。若显示「不支持」「不可用」或一直「等待线缆」，检查系统版本、线缆和电脑 USB 接口；无法提供 USB 连接时可先使用 Wi-Fi。

### 3.3 PICO USB 有线连接

1. 使用配套的新版电脑端和 PICO 应用。
2. 在 PICO 中开启开发者选项及 USB 调试。
3. 使用 USB 数据线连接电脑，在头显中允许这台电脑调试。
4. 打开两端程序，在头显「电脑」页选择带 `USB` 标记的电脑。

PICO USB 条目可能显示地址 `127.0.0.1`；应按电脑名称与 `USB` 标记选择，不必把它改成 Wi-Fi 地址。USB 状态只显示「已检测到」或「已连接」、没有 Mbps 数值时，也可以选择连接。

### 3.4 切换电脑或连接方式

同一台电脑可能同时出现 `WIFI` 和 `USB` 条目。打开「电脑」页，选择希望使用的条目；切换期间画面可能短暂中断。

电脑列表会自动刷新。拔线或网络改变后，等待可用条目重新出现，再选择连接。连接速率表示链路情况，不是实际视频码率，也不保证能持续以该数值串流。

## 4. 桌面操作与虚拟键盘

### 4.1 常用操作

以下操作用于桌面模式。进入游戏后，游戏按键以相应的 SteamVR 绑定为准。

| 操作 | Quest／PICO 常见手柄 | Steam Frame 手柄 |
| --- | --- | --- |
| 移动指针 | 将手柄指向桌面 | 将手柄指向桌面 |
| 鼠标左键 | 扳机，或右手 A | 扳机，或右手 A |
| 鼠标右键 | 右手 B | 右手 B |
| 拖动窗口 | 按住左键操作并移动指针 | 按住左键操作并移动指针 |
| 滚动页面 | 指向桌面后拨动摇杆 | 指向桌面后拨动摇杆 |
| 显示／隐藏菜单 | 单击菜单键 | 单击 View 菜单键 |
| 切换桌面／SteamVR 画面 | 快速双击同一个菜单键 | 快速双击同一个 View 菜单键 |
| 游戏中返回桌面并打开菜单 | 长按菜单键约 1 秒 | 长按 View 菜单键约 1 秒 |
| 打开／关闭虚拟键盘 | 桌面模式下按左手 X | 桌面模式下按右手 X |
| 切换电脑显示器 | 桌面模式下按左手 Y | 桌面模式下按右手 Y |
| 显示／隐藏性能面板 | 同时按下左右摇杆 | 同时按下左右摇杆 |

切换模式或重新连接后，如果快捷键没有响应，先松开按键，再重新按下。不同手柄的按键名称可能有差异，请结合头显菜单提示操作。

双击菜单键只切换观看的画面；需要启动或结束 SteamVR 时，使用菜单中的相应按钮。

### 4.2 多显示器与桌面大小

电脑连接多个显示器时，可在头显内查看桌面并使用换屏快捷键。桌面中的窗口仍由 Windows 管理。

需要放大或缩小桌面时，使用桌面上方出现的尺寸工具条；支持的范围为 0.5–2 倍。若工具条没有出现，先确认两端使用配套版本。

电脑「串流设置 → 画面设置」中的「保持桌面分辨率」用于保留 Windows 的分辨率、刷新率和显示器排列。希望连接头显时电脑显示设置保持原样，可启用此项；它与头显中桌面的物理大小是两项独立设置。

### 4.3 虚拟键盘

1. 在桌面中点击需要输入文字的位置。
2. 使用键盘快捷键，或点击菜单中的「虚拟键盘」。
3. 用手柄指向按键并按扳机输入。
4. 输入完毕后关闭键盘。

键盘支持中英文布局、常用导航键、复制与粘贴，以及 Shift、Ctrl、Alt、Win 等组合操作。修饰键用于下一次按键；中文输入仍需电脑配置可用的中文输入法。可以拖动键盘底部的拖拽条调整位置。

### 4.4 透视

在头显「设置」中按需开启：

- **未连接时透视**：在连接菜单后方显示现实环境。
- **桌面模式透视**：在桌面窗口外显示现实环境。

透视需要设备和系统支持；选项不可用时无法启用。桌面透视不会把 SteamVR 游戏自动变成混合现实应用。

## 5. SteamVR 游戏

### 启动游戏

1. 在电脑安装并登录 Steam，完成 SteamVR 安装。
2. 连接头显，确认桌面串流正常。
3. 打开头显菜单，点击「启动 STEAMVR」，等待 SteamVR 就绪。
4. 从 Steam、SteamVR 或电脑桌面启动游戏。

连接时电脑已经在运行 SteamVR 的，头显可能直接显示当前游戏画面；需要查看桌面时使用模式切换操作。

### 返回桌面或结束游戏

- **临时操作电脑**：在游戏中长按菜单键约 1 秒，返回桌面并打开菜单。
- **回到仍在运行的游戏**：双击菜单键切换到 SteamVR 画面。
- **结束 SteamVR**：先保存并退出游戏，再使用「关闭 STEAMVR」或电脑上的 SteamVR 退出操作。

更改分辨率、首选刷新率等设置后，如果出现「需要重启 SteamVR」，点击「稍后」可以先保留当前会话；保存游戏进度后再重启，使新设置生效。

## 6. 画质与流畅度

入口：电脑 **「串流设置 → 画面设置」**。

### 6.1 常用设置

| 设置 | 用途与调整方法 |
| --- | --- |
| 画面分辨率 | 高档位保留更多细节，也更考验电脑和头显。先连接头显查看对应尺寸；标红的「不支持」档位不要用于当前设备 |
| 首选刷新率 | 选择希望使用的刷新率。更高刷新率需要整套设备持续提供更多画面；头显实际支持情况优先 |
| 视频编码 | 决定可用画质与兼容性，见下表；更改后会重新连接 |
| 码率 | VR 视频使用的码率预算。较高值可能保留更多细节，也需要更稳定的网络；实际流量会随画面变化 |
| 自动调整 VR 码率 | 开启后根据可用网络情况调整；关闭后使用所选预算。初次使用或网络有波动时可保持开启 |
| 桌面模式串流码率 | 单独调整桌面观看的码率上限，最高 150 Mbps；网络不足时实际值仍可能降低 |
| 清晰度增强 | 「禁用／均衡／锐利」；均衡较柔和，锐利强调细节。用于 SteamVR SDR，桌面和 HDR 不适用 |
| Gamma 微调 | 1.00 保持原中间调；高于 1 提亮，低于 1 压暗。画面正常时保持 1.00 |
| 全局 FSR | 用部分细节换取较低图形负担；质量档更注重清晰度，性能档更注重流畅度。HDR 不适用 |
| 视频缓冲 | 开启有助于缓解网络波动；关闭可尝试降低延迟，但网络不稳定时可能更容易卡顿 |
| 缺帧平滑 | 缓解视频迟到时的视觉顿挫；不能代替稳定网络或提高游戏本身的性能 |
| 保持桌面分辨率 | 保留 Windows 显示设置，详见[桌面操作](#desktop) |

「全局 FSR」提供最高质量、超高质量、质量、均衡和性能档。界面中的倍率用于区分画质档位，不代表游戏帧数会按该倍率增长。

### 6.2 视频格式怎么选

| 格式 | 使用建议 |
| --- | --- |
| HEVC | 默认选择，兼顾画质与带宽 |
| H.264 | 出现兼容问题时可尝试 |
| H.264+ | 提供更高的可选码率，需要相应网络和设备能力 |
| HEVC-10Bit | 提供 10 位色彩；选择此项不等于开启 HDR。普通 HEVC 有兼容问题时，可在设备支持的前提下尝试 |
| AV1 | 需要电脑显卡与头显同时支持 |

连接头显后查看可选格式和不支持提示。Steam Frame 当前使用 H.264／HEVC。不要仅根据格式名称判断一定更清晰或延迟更低。

### 6.3 按需求调整

| 当前需求 | 可以按顺序尝试 |
| --- | --- |
| 先保证稳定 | 保留默认值 → 开启自动调整 VR 码率 → 降低码率或分辨率 |
| 看清桌面文字 | 先检查 Windows 的显示分辨率与缩放 → 调整头显中的桌面大小 → 适度提高桌面码率 |
| 改善游戏细节 | 适度提高分辨率 → 尝试清晰度增强「均衡」 → 网络允许时提高码率 |
| 游戏本身运行吃力 | 降低游戏画质或分辨率 → 选择较低刷新率 → 尝试全局 FSR |
| 网络偶尔波动 | 开启自动调整 VR 码率和视频缓冲，降低码率，改善无线连接环境 |
| 希望降低操作延迟 | 先降低过高的分辨率／码率；稳定连接后再比较关闭视频缓冲或帧生成的体验 |

每次只改一项，在同一游戏场景观察文字、快速转头、手部动作和操作响应。设置导致重影、画质下降或更明显的延迟时，恢复上一项设置。

## 7. 注视点串流

入口：电脑 **「串流设置 → 画面设置 → 注视点串流」**。

此功能优先保留注视区域的细节，允许外围画面降低细节。使用有效眼动追踪时可跟随视线；没有有效眼动数据时使用画面中心。可用效果取决于头显与电脑的支持情况。

### 使用步骤

1. 使用眼动设备时，先在相应软件或头显设置中开启眼动追踪并完成校准。
2. 在「注视点串流」中选择「延迟码率优先」或「清晰度优先」。
3. 查看状态文字，确认是「正在跟随注视」还是暂用画面中心。
4. 从中等注视区域开始，边看文字和场景细节，边调整下表中的选项。

| 选项 | 作用 |
| --- | --- |
| 禁用 | 关闭此功能 |
| 延迟码率优先 | 更注重响应速度与带宽节省 |
| 清晰度优先 | 更注重注视区域的细节 |
| 注视区域大小 | 从极小到极大；较大的区域更便于快速扫视，较小区域更节省带宽 |
| 外围压缩强度 | 范围 0–50；越高，外围可能越模糊。0 为最低压缩 |
| 注视区域清晰度 | 范围 0–12；越高越强调注视区域细节，也可能增加码率。0 保持原有画质 |
| 注视点调试 | 在支持的画面中显示青色清晰区域轮廓，方便检查位置和大小 |

使用外接 Cymple 眼追时，应在 Cymple 中启用精确模式并完成精确校准。清晰区域偏离视线时先检查权限、校准和状态提示。调试完成后关闭轮廓显示，恢复正常观看。

<a id="frame-generation"></a>

## 8. 帧生成

入口：电脑 **「串流设置 → 画面设置 → 帧生成」**。

帧生成用于让运动画面看起来更连贯。当前适用于 **SteamVR SDR 游戏串流**，桌面模式和 HDR 不适用。它不会让游戏本身的运行速度按同样比例提高，也不能保证解决卡顿。

### 使用步骤

1. 先关闭帧生成，确认游戏和连接可以稳定运行。
2. 将「帧生成」设为「启用」，等待短暂重连。
3. 选择「帧生成调度」和「帧生成方法」。首次尝试可从「动态＋内插帧」开始。
4. 对比快速转头、手部移动、细线、字幕和菜单的观看效果，并检查操作响应。

| 选项 | 使用时会有什么不同 |
| --- | --- |
| 调度：动态 | 保留游戏原有目标帧率，尝试改善观看流畅度 |
| 调度：静态 | 将游戏目标帧率设为头显刷新率的一半。例如 90 Hz 时目标为 45 FPS；可能增加操作延迟 |
| 方法：内插帧 | 补充游戏画面之间的过渡画面，快速运动或遮挡时仍可能有重影 |
| 方法：外推帧 | 尝试补充后续运动画面，方向突变或快速动作时可能出现预测误差 |

静态模式的目标不代表一定能稳定达到该帧率，也不保证头显一直显示满刷新率。若出现手部拖影、文字变形、画面闪动或响应变慢，将帧生成设为「禁用」后再次比较。

## 9. 音频与语音

入口：电脑 **「串流设置 → 音频与语音」**。

### 9.1 在头显听电脑声音

1. 启用「电脑音频」。
2. 播放电脑声音，在头显中确认能听到。
3. 用「VR 音量」调整串流音量，并检查头显自身音量。

「自动静音电脑音箱／耳机」默认开启：连接后电脑端静音，头显继续播放；断开或退出后恢复。如果希望电脑和头显同时出声，关闭此项。

### 9.2 在游戏中使用头显麦克风

1. 在头显上允许 Cymple Streamer 使用麦克风。
2. 启用「麦克风直通」。
3. 在「虚拟麦克风」中选择可用设备。使用默认 VB-CABLE 时，游戏里的录音设备选择 **CABLE Output**。
4. 在游戏或聊天软件中测试录音，并检查其静音或按键说话设置。

首次安装 VB-CABLE 后可能需要重启 Windows。列表中设备不可用时，先确认安装和重启完成，再点击「刷新设备」。

「自动选择麦克风」开启时，串流期间会自动选择对应的 Windows 默认录音设备。关闭此项仍可传输头显语音，但需要自行在游戏中选麦克风。结束串流后会恢复由 Cymple 改动的选择，并保留你在串流期间手动做出的设备更改。

使用 VoiceMeeter 等已有音频配置时，还需要在对应软件中开启所需通道。

### 9.3 识别语音与游戏麦克风的区别

「额外功能」的录入源选择「VR（头显麦克风）」时，只需保持串流连接、允许麦克风并开启麦克风传输，无需在语音识别页面选择 Windows 虚拟麦克风。让电脑游戏听到声音时，则按上一节选择游戏的录音设备。

## 10. 输入与追踪

入口：电脑 **「串流设置 → 输入与追踪」**。

| 功能 | 怎么使用 | 需要注意 |
| --- | --- | --- |
| 手部追踪 | 在头显系统允许手部追踪，再开启软件中的「手部追踪」 | 需要设备与游戏支持；显示手指动作不代表所有游戏都支持脱离手柄操作 |
| 眼动与面部追踪 | 完成设备授权和校准，在「面部追踪」中选择相应输出选项 | 眼动与面部能力取决于硬件；仅有眼动设备不代表能提供完整表情 |
| 全身追踪 | 先完成设备或追踪器的配对与校准，再开启「全身追踪」 | 在游戏内还需完成身体校准；开启开关不会为没有追踪能力的设备增加真实全身追踪 |

「面部追踪」提供：

- **VRChat Eye OSC**：用于兼容的 VRChat 眼动功能，按游戏要求开启 OSC。
- **VRCFaceTracking（Cymple 插件）**：需要另外准备 VRCFaceTracking 和对应 Cymple 插件，并使用支持相关表情的虚拟形象。

注视点串流、虚拟形象眼动和面部表情是不同的使用功能。判断是否正常时，应分别查看清晰区域、眼睛动作和表情效果。Steam Frame 或其他头显未提供的追踪能力，不能仅凭电脑端开关判断已经可用。

<a id="speech"></a>

## 11. 语音与翻译

入口：电脑 **「额外功能 → 语音与翻译」**。

| 功能 | 支持语言 |
| --- | --- |
| 语音转文字 | 中文、英文、日文、韩文、俄文 |
| 文字翻译 | 上述五种语言之间互译 |
| VRChat 聊天框输出 | 可多选上述五种语言 |
| 文字转语音 | 中文、英文、中英混合 |

首次使用按页面提示下载相应模型，下载完成后可以离线识别、翻译和朗读。软件保存设备和功能偏好；识别结果、翻译原文及译文不会写入设置，需要保留的文字请及时复制。

### 11.1 下载需要的内容

| 想使用的功能 | 页面中需要准备的项目 |
| --- | --- |
| 手动选择中、英、日、韩语识别 | 「中英日韩」识别模型 |
| 手动选择俄语识别 | 「俄语与自动判断」识别模型 |
| 自动判断识别语言 | 上述两个识别模型都下载 |
| 翻译文字或发送翻译后的聊天框内容 | 「下载翻译模型」 |
| 朗读文字 | 「文字转语音」中的中英模型 |

下载失败时可以重试；已下载内容无法使用时，可点击「重新下载模型」。识别、翻译和朗读是独立功能，只需准备自己使用的部分。

### 11.2 语音转文字

1. 勾选「启用语音转文字」。
2. 选择「录入源」：头显使用「VR（头显麦克风）」，电脑麦克风可选「系统默认麦克风」或具体设备。
3. 选择「识别语言」。短句或混合语言判断不准时，改为手动选择。
4. 确认所需模型已下载，点击「开始识别」，或按住所选手柄快捷键。
5. 正常说话，在句子之间稍作停顿；松开快捷键结束收音并处理最后一句。

默认快捷键是 **左手 X**，可在页面中改为左手 Y、右手 A 或右手 B。连接期间切换页面或最小化电脑窗口后仍可使用；重连后先松键，再按住开始。

页面保留最近 5 句结果，可「复制文字」「清空」或「用于语音播放」。关闭「启用语音转文字」会停止录入。识别可能出错，特别是短句、口音和混合语言；对内容有准确要求时请核对文字。

### 11.3 手动翻译

1. 在「五语翻译」中完成翻译模型下载。
2. 选择不同的原文语言和译文语言。
3. 输入或粘贴文字，或点击「填入识别结果」。单次手动原文最多 512 字符，长内容分段处理。
4. 点击「翻译」，完成后复制或编辑译文。中文、英文译文可以「用于语音播放」。

页面提供「取消翻译」和「释放内存」。默认设置适合先行使用；如果另有已配置好的「Hy-MT2 · 本机服务」，可在「翻译引擎」中选择它并填写地址。该选项需要自行准备服务，具体操作见页面中的「启动说明」。

### 11.4 将识别结果发送到 VRChat 聊天框

1. 在 VRChat 的 Action Menu 中开启 **OSC → Enabled**，见 [VRChat 官方使用说明](https://docs.vrchat.com/docs/osc-overview#enabling-it)。
2. 在 Cymple Streamer 中勾选「通过 OSC 直接输出到 VRChat」。
3. 至少勾选一种「输出语言」。需要翻译到其他语言时，先完成翻译模型下载。
4. 按住语音快捷键说话，停顿后查看聊天框内容。

可以同时选择多种输出语言；长内容会分页显示。部分翻译失败时，该句可能不会发送，请查看页面提示。关闭 OSC 或更改输出设置会取消旧的待发送内容。

软件显示已发送后，仍需在游戏中确认实际显示；其他人能否看见也受 VRChat 聊天框设置影响。语音识别内容可能直接公开给其他玩家，正式使用前先用简短测试句检查结果。

### 11.5 文字转语音

1. 完成「文字转语音」所需模型下载。
2. 输入中文、英文或中英混合文字，单次最多 2,000 字符。
3. 选择「输出设备」和「朗读语言」，按需调整语速、音量。
4. 点击「播放语音」；需要中止时点击「停止播放」。

要让 VRChat 等游戏听到朗读，输出设备选择虚拟音频设备的播放端，游戏选择相应录音端。例如，朗读输出选 **CABLE Input**，游戏麦克风选 **CABLE Output**。如果只想自己听，选择普通耳机或扬声器。

<a id="performance"></a>

## 12. 性能面板

入口：头显 **「设置 → 性能 Overlay」**，或同时按下左右摇杆切换显示。切换后需松开两个摇杆，再次按下才会再次切换。

| 面板项目 | 读法 |
| --- | --- |
| Framerate | 头显显示的新视频画面帧率；开启帧生成时可能包含生成画面，不等于游戏自身 FPS |
| Target framerate | 目标刷新率；设置了 90 Hz 不代表游戏一定达到 90 FPS |
| Latency | 软件报告的串流总延迟；结合实际操作响应判断 |
| Game／Encoding／Networking／Decoding | 游戏、编码、网络、解码相关延迟，用于初步判断哪一部分出现变化 |
| Frame queue／Display wait | 画面等待相关时间；不应只看单项数值判断整体体验 |
| Bitrate | 当前实际视频码率，会随场景和连接情况变化 |
| Max bitrate | 设置的码率预算，与实际码率分开看 |
| Connection | 当前连接方式与可获取的连接速率 |
| Graphics Quality／Render resolution | 当前画质档位与渲染设置 |
| Frame generation／Video buffering | 当前帧生成与缓冲状态 |
| GPU／Headset／Software version | 显卡、头显与软件版本信息，反馈问题时可一并提供 |

显示 `--` 通常表示暂时没有有效数据。比较设置效果时，保持相同游戏、场景和观看位置，综合观察画质、流畅度、延迟与断续情况；较高的面板帧率不能单独证明游戏性能提高。

<a id="maintenance"></a>

## 13. 更新与维护

### 更新程序

- **Windows**：收到新版本提示时，点击「立即下载」。先保存游戏进度、结束串流并关闭 SteamVR，再运行新安装器。
- **Android**：收到「头显 App 可更新」提示后下载配套 APK，再将文件安装到头显。点击下载不会自动完成头显安装。
- **Steam Frame**：使用配套专用安装器连接设备，选择「更新」。

版本信息可在两端「关于」中查看。更新后确认两端为配套版本，再重新连接。

### 驱动与防火墙

电脑「安装维护」提供「安装 / 更新串流驱动」和「添加防火墙规则」。SteamVR 无法识别头显时，可先关闭 SteamVR，再按页面操作安装或更新驱动。电脑无法被发现时，可检查防火墙规则。

这些操作可能需要 Windows 权限确认。驱动维护前先结束当前游戏，不要随意移除其他设备的驱动。

### 卸载

- Windows 电脑端通过 Windows「已安装的应用」卸载。
- Android 头显端在头显应用管理中卸载。
- Steam Frame 使用专用安装器的「卸载」。

共享的 VB-CABLE 音频设备不会随电脑端自动卸载；其他软件仍在使用时可以保留。

<a id="troubleshooting"></a>

## 14. 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 头显找不到电脑 | 电脑端是否已打开；两端是否同一局域网；是否使用访客 Wi-Fi／设备隔离；防火墙是否允许；VPN 是否影响连接 |
| USB 只充电、没有电脑条目 | 换用数据线或电脑 USB 接口；保持头显唤醒；Quest 检查 USB 网络提示，PICO 检查 USB 调试与授权 |
| PICO USB 没有显示连接速率 | 查看是否有 USB 电脑条目和「已检测到／已连接」状态；没有 Mbps 数字并不等于不可用 |
| Steam Frame 安装器找不到设备 | 开启开发者模式，检查线缆和授权，点击「刷新设备」并查看操作记录 |
| Steam Frame 安装后没有自动打开 | 从「库 → 非 Steam」打开对应 Devkit Game，再手动选择电脑 |
| 有声音但黑屏，或画面异常 | 先降低分辨率；检查所选视频格式是否受支持；尝试 HEVC 或 H.264；确认两端配套并重新连接 |
| SteamVR 无法启动或不识别头显 | 先确认桌面串流正常；关闭 SteamVR 后在「安装维护」安装／更新串流驱动；查看 SteamVR 是否阻止了 Cymple 插件 |
| 桌面正常，游戏明显卡顿 | 降低游戏画质、画面分辨率或目标刷新率；检查游戏自身运行情况，并临时关闭帧生成比较 |
| 网络延迟高、画面时断时续 | 开启自动调整 VR 码率，降低码率；电脑接网线、头显靠近路由器；停止占用网络的大文件传输 |
| 桌面文字模糊 | 检查 Windows 显示分辨率与缩放；调整头显中桌面大小；适度提高桌面码率 |
| 开启帧生成后手部或文字重影 | 比较其他生成方法，或关闭帧生成；不要只依据面板帧率判断效果 |
| 注视区域不跟随或位置不准 | 确认眼动设备、权限和校准；查看是否提示暂用画面中心；外接 Cymple 眼追检查精确模式 |
| 电脑没声音，头显有声音 | 检查「自动静音电脑音箱／耳机」；关闭后可让电脑出声 |
| 头显听不到电脑声音 | 开启「电脑音频」，检查 VR 音量、头显音量及电脑应用是否静音 |
| 游戏收不到头显麦克风 | 检查头显麦克风权限和「麦克风直通」；确认虚拟设备可用；默认路由下游戏选择 CABLE Output |
| 语音识别无法开始 | 勾选「启用语音转文字」；确认模型下载与录入源；使用 VR 录入时保持串流和麦克风传输 |
| 自动识别语言经常错误 | 手动选择识别语言，避免过短或连续混合多种语言的句子 |
| VRChat 聊天框没有内容 | 检查游戏 OSC 和聊天框设置、软件 OSC 开关及输出语言；需要翻译时确认模型就绪和页面没有报错 |
| 朗读只能自己听见 | 将朗读输出改为虚拟设备的播放端，并在游戏选择对应录音端，例如 CABLE Input／CABLE Output |
| 修改设置后没有变化 | 看是否需要重连或重启 SteamVR；保存游戏后按提示操作；检查当前设备是否支持该项 |
| 只看到警告和错误，没有完整过程 | 电脑「运行日志」用于查看重要提示；需要更多信息时点击「打开日志目录」或导出诊断包 |

问题仍在时，记录发生时间和操作顺序，再按下一节提供日志。请尽量在问题发生后及时反馈，避免日志过期。

<a id="feedback"></a>

## 15. 日志与问题反馈

### 查看与保存日志

电脑「运行日志」提供「刷新」「复制全部」和「打开日志目录」。头显「日志」可查看连接信息；Steam Frame 安装问题使用安装器的「操作记录」。

电脑端、Android 端和 Steam Frame 端的应用日志按近 **48 小时**保留。需要排查的问题请及时保存相关记录。

### 导出或提交反馈

入口：电脑 **「问题反馈」**。

1. 选择「BUG汇报」或「改进建议」。
2. 写清现象、复现步骤和预期结果；联系方式可选。
3. 按需添加截图或其他附件。页面会说明诊断包包含的日志和配置。
4. 希望先自行查看时，点击「导出诊断包（不发邮件）」，再「打开诊断包目录」。
5. 准备发送时，核对内容与附件，勾选页面中的发送同意选项，点击「确认发送」。

日志和配置可能包含设备、网络和电脑路径信息，额外附件按原文件发送。发送前请核对要分享的内容；如果软件提示无法确认是否送达，先联系维护者确认，避免立即重复发送。

反馈中建议包含：
